# Documentación externa

Los manuales y hojas de datos originales se conservan únicamente en la copia local de trabajo y no se redistribuyen en este repositorio público. Esta decisión evita publicar metadatos, ejemplos de credenciales incluidos por los fabricantes y documentos cuya licencia de redistribución no está confirmada.

## Equipos documentados

- Bosch 7000i y 8000i: configuración de cámaras y API RCP.
- Dragino / Seeeduino LoRaWAN: comandos AT, biblioteca y configuración EU868.
- Milesight: transmisores y sensores LoRaWAN.
- IMBuildings People Counter: contador infrarrojo.
- Adeunis Motion V2.
- Dragino CPL01.
- Milesight AM107.
- Milesight EM320.
- Milesight EM500.
- Milesight WS202.
- SenseCAP S2101.

Para consultar versiones actualizadas, utiliza el centro de descargas oficial del fabricante correspondiente. No copies al repositorio claves, DevEUI, IP, SSID o credenciales que aparezcan durante la configuración de un dispositivo real.
